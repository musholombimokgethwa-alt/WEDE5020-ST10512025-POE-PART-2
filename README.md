# WEDE5020-ST10512025-POE-PART-2
part two was about puting colour using  external CSS and making a  responsive design that works well on different screen sizes such as desktops, tablets and mobile phones.

Features included in the website:

* A fixed navigation bar
* Background images
* Styled headings and paragraphs
* Buttons with hover effects
* Responsive design using media queries
* Smooth layout and spacing
* External CSS styling

The website uses colours, fonts and spacing to create a professional appearance and improve the user experience. Media queries were used to make sure the layout adjusts correctly on smaller screens
